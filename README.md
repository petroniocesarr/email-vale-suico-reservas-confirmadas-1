# Vale Suíço Resort — E-mail Marketing: Reservas Confirmadas

Template de confirmação de reserva informando status de inserção no sistema, atrativos aquáticos e canais de atendimento.

---

## 📋 Especificações Técnicas

- **Formato:** HTML Responsivo para E-mail Marketing (Table-based layout)
- **Largura Máxima:** 600px centralizado
- **Compatibilidade:** Testado para Gmail, Outlook (Desktop & Web), Apple Mail, Yahoo e dispositivos móveis (iOS / Android)
- **Tipografia:** Montserrat (Google Fonts) com fallback para Arial, Helvetica, sans-serif
- **Paleta Institucional:**
  - Azul Institucional: `#2a3a76`
  - Dourado Suíço: `#d6a872` / `#c48b3f`
  - Fundo Contêiner: `#ffffff`
  - Fundo Geral: `#f4f4f4`
- **Assets inclusos:** 4 imagens otimizadas com praia de ondas, playground aquático infantil e Equipe de Monitores & Lazer.
- **Tags Dinâmicas:** Suporta personalização dinâmica via tag `*!NOME!*` (adaptável para tags de CRM como `{{ primeiro_nome }}`, `*|FNAME|*`, etc.)

---

## 📁 Estrutura de Arquivos

```
├── index.html        # Arquivo HTML principal pronto para envio
├── assets/           # Pasta contendo todas as imagens locais em alta definição
└── VALE-SUIÇO_EMAIL_RESERVAS CONFIRMADAS_1.zip  # Pacote compactado pronto para importação direta em plataformas de disparo
```

---

## 🚀 Como Utilizar

1. **Importação Direta em Ferramentas de Disparo (Mailchimp, RD Station, HubSpot, Brevo, ActiveCampaign):**
   - Faça o upload do arquivo `VALE-SUIÇO_EMAIL_RESERVAS CONFIRMADAS_1.zip` diretamente no gerenciador de templates da sua plataforma.
2. **Utilização do Código Fonte:**
   - Abra o `index.html`, copie o código-fonte e cole no editor HTML da plataforma desejada. As imagens locais na pasta `assets/` podem ser hospedadas em seu servidor/CDN ou mantidas com o pacote.
